### Misc Tips

In no particular order, here are some suggestions from pentestmonkey readers.

**From Dan Crowley:** [A way to extract data via SQLi with a MySQL backend](http://www.notsosecure.com/folder2/2010/06/29/mysql-exploitation-with-error-messages)

**From Jeremy Bae:** Tip about sp\_helpdb – included in table above.

**From Trip:** List DBAs (included in table above now):

> select name from master..syslogins where sysadmin = ’1′

**From Daniele Costa:** Tips on using fn\_my\_permissions in 2005, 2008 – included in table above. Also: To check permissions on multiple database you will have to use the following pattern.

> USE \[DBNAME\]; select permission\_name FROM fn\_my\_permissions (NULL, ‘DATABASE’)

Note also that in case of using this data with a UNION query a collation error could occur. In this case a simple trick is to use the following syntax:

> select permission\_name collate database\_default FROM fn\_my\_permissions (NULL, ‘DATABASE’)
